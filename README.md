# PHP Outside Tracker

## About

This is an outside activity tracker written in PHP. You are able to add activities you do outside for an amount of time to your account. Your goal is to reach 4 hours of outside time every single day. There is a daily goal tracker and 91 day heat map to help keep you locked in on your goal!

## Technology

This is built with PHP (it's my first time using PHP)! For the Database I am using MySQL and it's deployed with Docker.
